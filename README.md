# WaterGate

Prohlížeč WaterGate (Gecko / Firefox) pro Windows, Linux a Android.

Stáhněte poslední verzi v [Releases](../../releases/latest). Nainstalovaný WaterGate se pak aktualizuje sám.

## Zdrojový kód

WaterGate je postavený na jádru prohlížeče Firefox od Mozilly a je šířený pod licencí [Mozilla Public License 2.0](https://www.mozilla.org/MPL/2.0/). Zdrojový kód každé verze WaterGate je přiložený u jejího vydání jako `WaterGate-source.zip`; zdrojový kód Firefoxu najdete na [archive.mozilla.org](https://archive.mozilla.org/pub/firefox/releases/).
